# Project instructions

- Use concise ASD-STE100 Simplified Technical English.
- Read current files and preserve user changes.
- Write self-documenting code. Add comments only when necessary.
- Keep host rules separate. Use current official host documentation.
- Never sort rules, insert status defaults, or drop tokens during formatting.
- Keep the core independent of the editor and free of runtime dependencies.
- Keep browser extension support free of Node-only runtime APIs.
- Run type, lint, formatting, unit, grammar, build, and editor checks for relevant changes.
- Record verification and open checks in docs/verification.md.
- Treat commit, push, installation, and Marketplace publication as separate actions. Do not publish or push unless asked.
